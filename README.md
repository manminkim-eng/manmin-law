## 2. 매월 갱신 절차 (3단계)

### ① 데이터 파일 추가

`data/` 폴더에 새 파일을 만듭니다. 파일명은 반드시 `YYYY-MM.json`.

```bash

```

### ② 빌드

```bash
cd "41.개발자료[건축법규]"
python build.py
```

```
  생성  2026-08.html   (15건)
  생성  2026-07.html   (18건)
  ...
  생성  index.html      (총 6개호)
```

### ③ GitHub 반영

```bash
git add .
git commit -m "2026-08 법규 검토 요약"
git push
```

푸시 후 1~2분이면 GitHub Pages에 반영됩니다.

## 3. JSON 작성 규칙

```jsonc
{
  "issue":    "2026-08",                    // 파일명과 동일 (필수)
  "label":    "2026년 8월",                 // 화면 표시명
  "published":"2026-09-01",                 // 발행일
  "source":   "법규교육 PPT(26년08월).pdf",  // 원본 자료명
  "headline": "이번 호 핵심 3줄 요약",

  "items": [
    {
      "cat":  "시행법령",
      "field":["건축","소방"],
      "law":  "건축법 시행령",
      "title":"항목 제목",
      "dateLabel":"시행",
      "date": "2026-08-15",
      "deadline": "2026-09-20",             // (선택) 예고 마감일 → D-day 자동표시
      "summary":"한두 문장 요약",
      "reason": "제안이유 및 주요내용 (개정 배경·취지 서술)",
      "detail":[ "조문별 세부내용", "..." ], // (선택) 접었다 펴는 영역
      "compare":[ {"a":"제61조①","o":"현행 조문 요지","n":"개정(안) 요지"} ], // (선택) 신·구조문 대비표
      "compareNote":"대비표가 없을 때 사유(제정법·시행예정본 미공개 등)",   // compare 없을 때만
      "impact":"실무 영향 한 줄",            // (선택) 금색 강조 박스
      "link":"https://...",                 // (선택) 원문 링크 직접 지정
      "linkLabel":"제정안 원문 ↗"           // (선택)
    }
  ]
}
```

### cat (구분) — 이 7가지만 사용

| 값 | 색상 | 용도 |
|---|---|---|
| `시행법령` | 금색 | 이미 공포·시행 확정 |
| `국회통과` | 적색 | 본회의 통과, 공포 대기 |
| `훈령예규고시` | 보라 | 고시·훈령·예규 |
| `입법예고` | 청색 | 법령 입법예고 |
| `행정예고` | 녹색 | 지침·시방서 행정예고 |
| `의원발의` | 주황 | 발의 단계 |
| `추가검토` | 회색 | 지자체 운영기준·KDS·참고자료 |

### field (분야)

`건축` `구조` `기계설비` `소방` `토목` `전기` `도시계획` `안전진단` `환경` 등 자유롭게.
필터 칩이 자동 생성됩니다.

### 원문 링크 자동 생성 규칙

| 자료 유형 | 연결되는 곳 |
|---|---|
| 일반 법령·시행령·시행규칙 | 법제처 `law.go.kr/법령/OOO` |
| 고시·훈령·예규 (`ADMIN_RULES` 등록분) | 법제처 `law.go.kr/행정규칙/OOO` |
| KDS·KCS·표준시방서 | 국가건설기준센터 `kcsc.re.kr` |
| 조례 | 자치법규정보시스템 `elis.go.kr` |
| 조달청 기준 | 나라장터 `pps.go.kr` |
| 의원발의·국회통과 | 2차 링크가 의안정보시스템으로 연결 |
| 입법·행정예고 | 2차 링크가 국민참여입법센터로 연결 |

새 고시가 추가되면 `build.py` 의 `ADMIN_RULES` 집합에 법령명을 넣어주면 됩니다.
어느 규칙에도 안 맞으면 JSON에 `"link"` 를 직접 써서 지정하세요.

## 4. 사이트 기능

| 기능 | 설명 |
|---|---|
| 검색 | 법령명·조문·키워드 실시간 필터. 단축키 `/` |
| 구분·분야 필터 | 칩 클릭. 건수가 함께 표시됨 |
| D-day | 입법예고 마감·시행예정일까지 남은 일수 자동 계산. 10일 이내면 적색 |
| 세부내용 | 항목별 접기/펴기, 우상단 `전체 펼치기` |
| 인쇄·PDF | A4 최적화. 인쇄 시 세부내용 자동 전개, 링크 URL 병기 |
| 공유 | 모바일은 카카오톡 등 네이티브 공유, PC는 링크 복사 |
| 항목 링크 | 각 카드의 `🔗 링크` — 특정 조항만 콕 집어 공유 |
| 원고 추출 | 네이버 블로그용 / 유튜브 대본용 텍스트 자동 생성 → 복사 |
| 다크·라이트 | 우상단 `◐`. 선택값은 브라우저에 저장됨 |
| index 대시보드 | 예고 마감·시행 예정 임박 항목을 날짜순으로 상단 노출 |

원고 추출은 **현재 필터에 표시된 항목만** 뽑습니다.
예를 들어 `소방` 분야만 필터한 뒤 추출하면 소방 관련 원고만 나옵니다.

## 5. GitHub 배포

**전용 저장소 `manmin-law` 를 사용합니다.** (2026-08 이전)

이전에는 `KIMMANMIN/law/` 하위에 두었으나, 포털 PWA(`MANMIN`)의 스코프가
`/KIMMANMIN/` 전체라서 그 안에 있는 법규 사이트는 **Chrome 이 별도 앱으로 설치해 주지 않습니다.**
(주소창에 설치 아이콘 대신 "앱에서 열기" 만 표시됨)
그래서 스코프가 겹치지 않는 독립 저장소로 분리했습니다. **다시 하위 폴더로 옮기지 마십시오.**

```bash
# 1) 저장소를 로컬에 받기 (이미 있으면 생략)
git clone https://github.com/manminkim-eng/manmin-law.git
cd manmin-law

# 2) 이 폴더 내용을 저장소 루트로 복사
xcopy /E /I /Y "Z:\MIN-A\01.만민자료\02.설계자료\11.개발자료\41.개발자료[건축법규]\버전s-1.0\*" .

# 3) 푸시
git add .

git push
```

이후 접속 주소:
